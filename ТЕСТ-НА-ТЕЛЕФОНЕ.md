# Тест на телефоне: инструкция для чайников

Цель: получить файл приложения, скачать его на телефон и установить. Собирается всё в облаке GitHub — ставить на компьютер ничего не нужно. Компьютер нужен один раз, только с браузером.

Понадобится: аккаунт Google, аккаунт GitHub (бесплатный, github.com), телефон на Android.

---

## Часть 1. Firebase (10 минут)

**1. Создайте проект.** Откройте console.firebase.google.com → «Создать проект» → имя любое (например, `carapp`) → Google Analytics **выключите** → «Создать».

**2. Добавьте приложение и скачайте ключ.**
- На главной странице проекта нажмите значок Android (зелёный робот).
- «Имя пакета Android»: вставьте `com.carapp`
- «Отладочный сертификат SHA-1»: вставьте `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25`
- «Зарегистрировать приложение» → «Скачать google-services.json» → сохраните файл. Дальше жмите «Далее» до конца.

**3. Включите вход по почте.** Слева «Сборка» → «Authentication» → «Начать» → вкладка «Способ входа» → «Электронная почта/пароль» → включить → «Сохранить».

**4. Создайте базу.** Слева «Сборка» → «Firestore Database» → «Создать базу данных» → место любое (для теста неважно) → режим «Производственный» → «Создать».
Потом вкладка «Правила»: удалите весь текст, вставьте текст из файла `src/services/firestore.rules` из этого архива → «Опубликовать».

---

## Часть 2. GitHub (5 минут)

**5. Создайте репозиторий.** github.com → значок «+» вверху справа → «New repository» → имя `car-app` → выберите **Public** → «Create repository».
(Public нужен, чтобы скачать файл на телефоне без входа. Секретных ключей в коде нет: ключ Firebase вы положите отдельно, в «секрет».)

**6. Загрузите файлы.** На странице нового репозитория нажмите ссылку «uploading an existing file». Распакуйте архив, откройте папку `car-app`, выделите **всё внутри** (Ctrl+A) и перетащите в окно браузера. Дождитесь загрузки (около 70 файлов) → внизу «Commit changes».

Проверьте: в репозитории должна быть папка `.github` → `workflows` → `build-test-apk.yml`. Если её нет (на Mac скрытые папки не видны — нажмите Cmd+Shift+.), сделайте вручную: «Add file» → «Create new file» → в имени напишите `.github/workflows/build-test-apk.yml` → вставьте содержимое этого файла из архива → «Commit changes».

**7. Положите ключ Firebase в «секрет».** В репозитории: «Settings» → «Secrets and variables» → «Actions» → «New repository secret».
- Name: `GOOGLE_SERVICES_JSON`
- Secret: откройте скачанный `google-services.json` в Блокноте, выделите весь текст (Ctrl+A), скопируйте (Ctrl+C) и вставьте сюда.
- «Add secret».

---

## Часть 3. Сборка (15–25 минут ожидания)

**8.** Вкладка «Actions» → слева «Собрать тестовое приложение» → справа «Run workflow» → зелёная кнопка «Run workflow».

**9.** Ждите. Зелёная галочка = готово. Красный крестик = ошибка: откройте шаг с крестиком, скопируйте последние 30–40 строк (или сделайте скриншот) и пришлите — найдём причину. Ошибки первых шагов написаны простыми словами.

**10.** Откройте завершённый запуск и прокрутите вниз до блока «Итог» — там ссылка на файл. Она всегда одна и та же:
`https://github.com/ВАШ-ЛОГИН/car-app/releases/latest/download/car-app-test.apk`

---

## Часть 4. Установка на телефон

**11.** Откройте эту ссылку в Chrome на телефоне — скачается `car-app-test.apk`. Нажмите на скачанный файл.
- Если телефон пишет «Установка из этого источника запрещена» — нажмите «Настройки» и разрешите для Chrome.
- Если Google Play Protect предупреждает — нажмите «Всё равно установить».

**12.** Чтобы дать приложение другому человеку — отправьте ему ту же ссылку.

---

## Что работает в таком тесте, а что пока нет

Работает: регистрация по почте, согласие на обработку данных, гараж, автомобили, записи о ТО, расходы, напоминания, замок по отпечатку.

Пока не работает (нужны отдельные шаги, скажем, когда понадобится):
- вход через Google — нужен ещё один код в `src/config.ts`;
- вход через Telegram и кнопка «Удалить аккаунт» — нужно развернуть серверные функции;
- обмен данными между двумя телефонами — нужно создать индексы в Firestore.

Тексты политики конфиденциальности будут содержать пометки «[НЕ ЗАПОЛНЕНО: …]» — это нормально для теста, реквизиты заполняются в `legal/operator.json` перед публикацией.

## Как собрать заново после правок

Загрузите изменённые файлы в репозиторий (Add file → Upload files) и снова запустите шаг 8. Ключ повторно вводить не нужно.
