# Скриншоты и тестовый аккаунт для модератора

## Что требует RuStore к скриншотам
- Минимум **3** для телефона, можно до 10. PNG или JPG, до 3 МБ.
- Рекомендуемое соотношение **16:9**; всё, что шире, магазин обрежет по краям. У вашего телефона экран
  вытянутее (примерно 20:9), поэтому сырой снимок обрежется и потеряет верх или низ.
- **Нельзя:** системные элементы Android (строка состояния сверху, кнопки навигации снизу), реклама сторонних
  сервисов (рекламное окно Яндекса), функции, которых нет, заставки и экраны входа в качестве единственных
  кадров, кликбейт.
- Текст на скриншотах — на русском. Показывайте настоящий интерфейс, а не только картинки.

## План из 5 кадров (вертикальные)
1. **Главная** — машина, пробег, ближайшее напоминание, сводка расходов за месяц.
2. **Сервис** — список записей, у одной видно описание работ, разбивку «работы / запчасти» и значок фото.
3. **Расходы** — сводка за месяц, разбивка по категориям и карточка «Средний расход».
4. **Напоминания** — ОСАГО, техосмотр, своё напоминание.
5. **Гараж** — несколько машин и (или) экран «Передача машины» с QR-кодом.

## Как снимать
- Сначала создайте **тестовые данные**: вымышленная машина (марка, модель и **выдуманный** номер), 4–5 записей
  о ТО с разными типами, расходы за месяц с заправками, пара напоминаний. Своих реальных номеров, почт и
  чеков не показывайте — скриншоты публичны.
- Рекламное окно появляется при запуске: закройте его и снимайте уже внутри приложения.
- Снимайте обычными скриншотами телефона, **ничего не обрезая**.
- **Пришлите мне сырые снимки** — я срежу системные панели и приведу к формату 1080×1920 (9:16) без
  потери интерфейса (с тёмными полями цвета приложения по бокам), чтобы магазин ничего не обрезал.

## Тестовый аккаунт для модератора (п. 8.5)
Модератор должен суметь войти и увидеть приложение с данными. Без этого частая причина отказа.

1. Зарегистрируйте в **настоящем** приложении аккаунт по почте и паролю, например
   `rustore-test@<ваш домен>` (подойдёт любая; подтверждения почты приложение не требует) и простой пароль.
2. Примите согласие, добавьте вымышленную машину, несколько записей ТО и расходов, пару напоминаний.
3. Проверьте, что на другом телефоне (или после выхода из аккаунта) вход по этой почте и паролю проходит и
   данные на месте.

Текст для поля «Комментарий модератору» (подставьте почту и пароль):
```
Приложение для учёта обслуживания и расходов на автомобиль. Тестовый аккаунт для проверки: вход по почте и паролю на экране входа. Почта: ____ Пароль: ____. В аккаунте уже есть тестовые данные (автомобиль, записи об обслуживании, расходы, напоминания). После входа принимается согласие на обработку данных (отдельный экран). Вход через Яндекс ID и Telegram необязателен. Удаление аккаунта: «Гараж» → «Удалить аккаунт и все данные». При запуске показывается рекламное окно Рекламной сети Яндекса (закрывается кнопкой).
```
